# Weather Telegram Bot (aiogram)

Bot Telegram për motin (aiogram, Python) — dërgo qytetin dhe merr parashikimin e motit.

`Python` `aiogram` `Telegram`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Weather-Telegram-Bot/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Vendos BOT_TOKEN në .env, `pip install -r requirements.txt`, pastaj `python main.py`.
